# 🚀 C# Completo: Programação Orientada a Objetos + Projetos
Este repositório contém todos os laboratórios, exercícios de fixação e projetos práticos desenvolvidos por mim durante o curso **C# COMPLETO Programação Orientada a Objetos + Projetos** do Prof. Dr. Nelio Alves na Udemy.

O objetivo deste repositório é consolidar a transição dos meus conhecimentos de desenvolvimento backend (vividos anteriormente em ecossistemas como Java/Spring) para o ecossistema moderno do **.NET e C#**.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas
* **Linguagem:** C# (.NET Core)
* **IDE:** Visual Studio / VS Code
* **Paradigma:** Programação Orientada a Objetos (POO)

---

## 📚 Principais Conceitos Praticados
* **Fundamentos da Linguagem:** Sintaxe, tipos de dados, estruturas condicionais e de repetição.
* **Orientação a Objetos Avançada:** Construtores, encapsulamento, herança, polimorfismo e interfaces.
* **Recursos Específicos do C#:** Expressões Lambda, Delegates, Propriedades automáticas e Generics.
* **Manipulação de Dados:** Uso robusto de **LINQ** (Language Integrated Query) e Expressões SQL-like.
* **Tratamento de Exceções:** Criação de exceções personalizadas e blocos try-catch estruturados.
* **Boas Práticas:** Princípios SOLID, Clean Code e organização de pastas arquiteturais.

---

## 📂 Estrutura do Repositório
* `/Exercicios-Fixacao`: Pequenos desafios para fixação de lógica, arrays, matrizes e POO básica.
* `/Projetos`: Aplicações completas desenvolvidas ao longo dos módulos (Ex: Sistema de xadrez/damas em console, sistemas de vendas/pedidos).

---

## 🎯 Próximos Passos
Após a conclusão da base da linguagem neste curso, os próximos passos envolvem o desenvolvimento de **Web APIs assíncronas com ASP.NET Core** e persistência de dados utilizando o **Entity Framework Core**.
